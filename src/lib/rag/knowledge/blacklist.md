# Debarment lists are fragmented

India lacks a single national debarment registry. CPSEs publish vendor blacklists on their own sites; some ministries maintain consolidated lists. Checking therefore requires querying each relevant buyer's published list plus general web search of firm name with terms like debarred or banned.

## Documentation requirement

Record which lists were consulted with dates. Absence from consulted lists is negative-evidence only, not proof of good standing.
